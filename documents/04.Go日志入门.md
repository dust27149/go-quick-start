# Go 日志入门

日志的作用不是“把信息打印出来”这么简单，而是记录程序在运行过程中的关键状态，方便排障、回溯和分析问题。

通常建议至少记录这些信息：

- 程序启动和结束
- 关键业务步骤开始与结束
- 外部请求的成功与失败
- 失败时的错误原因

相比直接到处写 `fmt.Println`，统一日志更适合真实项目，因为它能集中管理输出格式、输出目标和文件生命周期。

版本基准：本文档以 Go 1.26.5 为基准进行介绍。

## 1. 最小日志示例

`log` 是 Go 标准库里最常用的基础日志工具。最小写法如下：

```go
package main

import "log"

func main() {
	log.Println("程序启动")
}
```

这个例子只说明一件事：程序能把信息写出来。真正进入项目时，通常还会进一步统一日志格式、增加文件输出，或者同时输出到控制台和文件。

## 2. 输出到文件

如果希望日志落到文件里，可以用 `os.OpenFile` 打开或创建文件，再把文件交给 `log.New`。

```go
package main

import (
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile(
		"app.log",
		os.O_CREATE|os.O_WRONLY|os.O_APPEND,
		0666,
	)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	logger := log.New(
		file,
		"",
		log.Ldate|log.Ltime|log.Lshortfile,
	)

	logger.Println("程序启动成功")
}
```

这里的关键点是：

- `os.O_CREATE`：文件不存在时创建
- `os.O_WRONLY`：只写
- `os.O_APPEND`：追加写入
- `log.Ldate|log.Ltime|log.Lshortfile`：带日期、时间和简短文件位置信息

## 3. 同时输出到控制台和文件

开发时常见需求是：控制台实时看，文件里长期保存。这个场景通常用 `io.MultiWriter`。

```go
package main

import (
	"io"
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile(
		"app.log",
		os.O_CREATE|os.O_WRONLY|os.O_APPEND,
		0666,
	)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	writer := io.MultiWriter(os.Stdout, file)
	logger := log.New(writer, "", log.Ldate|log.Ltime|log.Lshortfile)

	logger.Println("程序启动")
	logger.Println("日志同时写入控制台和文件")
}
```

这个写法的好处是：

- 开发时能直接看到输出
- 线上仍然保留文件日志
- 只需要维护一套日志入口

## 4. 项目里怎么统一初始化日志

在实际项目中，建议把日志初始化单独封装，避免散落在各个业务函数里。

下面是一个很小的模板示例：

```go
package logger

import (
	"io"
	"log"
	"os"
)

func New(logFile string) (*log.Logger, *os.File, error) {
	file, err := os.OpenFile(logFile, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)
	if err != nil {
		return nil, nil, err
	}

	writer := io.MultiWriter(os.Stdout, file)
	logger := log.New(writer, "", log.Ldate|log.Ltime|log.Lshortfile)
	return logger, file, nil
}
```

在 `main` 里使用时可以这样写：

```go
logger, logFile, err := logger.New(cfg.LogFile)
if err != nil {
	log.Fatal(err)
}
defer logFile.Close()
```

这种写法的核心思路是：

- 初始化放在一处
- 输出目标放在一处
- 关闭文件的责任也放在一处

## 5. 日志写什么更合适

日志不是越多越好，而是要有用。比较实用的内容包括：

- 当前做到了哪一步
- 请求哪个地址
- 失败时具体的错误信息
- 结果状态码或业务结果
- 程序是否正常结束

例如：

```go
logger.Println("程序启动")
logger.Printf("开始请求: %s", url)
logger.Printf("请求失败: %s, err=%v", url, err)
logger.Printf("请求成功: %s, status=%d", url, status)
logger.Println("全部任务完成")
```

同时建议注意这些常见问题：

- 不要只打印成功路径，失败路径也要有上下文
- 不要把所有逻辑都塞进 `main.go`
- 不要让日志文件句柄长时间不关闭
- 不要把“固定前缀”误写成“动态等级”

## 6. 日志轮转完整示例

如果日志持续增长，通常还会加入轮转机制：

- 单个日志文件超过阈值后，压缩成 `.gz`
- 日志目录总大小超过阈值后，删除最早的归档

下面这个示例直接取自 `test.go` 的实现思路，使用标准库 `log` 和自定义 `io.Writer`，可以直接复制运行。

文字版流程图：

```text
main()
  -> newRotatingWriter("log/app.log")
  -> log.New(io.MultiWriter(os.Stdout, writer), ...)
  -> logger.Printf(...)
  -> log.Logger 把内容交给 io.Writer
  -> io.MultiWriter 分发写入
	  -> os.Stdout.Write(...)
	  -> rotatingWriter.Write(...)
  -> rotatingWriter.Write(...) 判断是否超过阈值
	  -> 未超过：直接写入当前 app.log
	  -> 超过：rotateLocked()
		  -> 关闭当前文件
		  -> nextArchiveNameLocked()
		  -> compressFile()
		  -> 重新打开 app.log
		  -> cleanupArchivesLocked()
```

```go
package main

import (
	"compress/gzip"
	"fmt"
	"io"
	"log"
	"os"
	"path/filepath"
	"sort"
	"strconv"
	"strings"
	"sync"
	"time"
)

const (
	rotateSizeBytes int64 = 2 * 1024  // 单个日志文件超过 2KB 就轮转，方便直接观察效果
	maxDirSizeBytes int64 = 10 * 1024 // 日志目录超过 10KB 就清理最早的归档
)

type rotatingWriter struct {
	mu            sync.Mutex // 保护下面这些字段，避免并发写日志时状态错乱
	path          string      // 当前日志文件路径
	dir           string      // 日志目录
	file          *os.File    // 当前打开的日志文件句柄
	currentSize   int64       // 当前文件已写入的字节数
	rotateSize    int64       // 单个文件的轮转阈值
	maxDirSize    int64       // 整个日志目录的大小阈值
	archivePrefix string      // 归档文件名前缀
}

func newRotatingWriter(logPath string) (*rotatingWriter, error) {
	// 先准备目录，再以追加模式打开日志文件，避免覆盖历史内容。
	dir := filepath.Dir(logPath)
	if dir != "." {
		if err := os.MkdirAll(dir, 0755); err != nil {
			return nil, err
		}
	}

	file, err := os.OpenFile(logPath, os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)
	if err != nil {
		return nil, err
	}

	// 读取现有文件大小，避免程序重启后从 0 开始误判轮转。
	info, err := file.Stat()
	if err != nil {
		file.Close()
		return nil, err
	}

	return &rotatingWriter{
		path:          logPath,
		dir:           dir,
		file:          file,
		currentSize:   info.Size(),
		rotateSize:    rotateSizeBytes,
		maxDirSize:    maxDirSizeBytes,
		archivePrefix: filepath.Base(logPath) + ".",
	}, nil
}

func (w *rotatingWriter) Write(p []byte) (int, error) {
	w.mu.Lock()
	defer w.mu.Unlock()

	// 每次真正写日志前检查大小，超限就先轮转。
	if w.currentSize+int64(len(p)) > w.rotateSize {
		if err := w.rotateLocked(); err != nil {
			return 0, err
		}
	}

	n, err := w.file.Write(p)
	w.currentSize += int64(n)
	return n, err
}

func (w *rotatingWriter) Close() error {
	w.mu.Lock()
	defer w.mu.Unlock()

	// Close 只负责收尾关闭当前文件。
	if w.file == nil {
		return nil
	}

	err := w.file.Close()
	w.file = nil
	return err
}

func (w *rotatingWriter) rotateLocked() error {
	// 轮转顺序：关闭旧文件 -> 压缩归档 -> 打开新文件 -> 清理旧归档。
	if w.file != nil {
		if err := w.file.Close(); err != nil {
			return err
		}
	}

	archiveName, err := w.nextArchiveNameLocked()
	if err != nil {
		return err
	}
	if err := compressFile(w.path, archiveName); err != nil {
		return err
	}

	newFile, err := os.OpenFile(w.path, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0666)
	if err != nil {
		return err
	}

	w.file = newFile
	w.currentSize = 0

	// 轮转完成后，再顺手清理过旧归档。
	return w.cleanupArchivesLocked()
}

func (w *rotatingWriter) cleanupArchivesLocked() error {
	// 扫描日志目录，只处理历史归档，不删除当前正在写的 app.log。
	entries, err := os.ReadDir(w.dir)
	if err != nil {
		return err
	}

	type archiveInfo struct {
		path    string
		size    int64
		modTime time.Time
	}

	var archives []archiveInfo
	var totalSize int64

	// 统计目录总大小，同时收集可删除的 gzip 归档。
	for _, entry := range entries {
		info, err := entry.Info()
		if err != nil {
			return err
		}

		if entry.Name() == filepath.Base(w.path) {
			totalSize += info.Size()
			continue
		}

		totalSize += info.Size()
		if strings.HasPrefix(entry.Name(), w.archivePrefix) && strings.HasSuffix(entry.Name(), ".gz") {
			archives = append(archives, archiveInfo{
				path:    filepath.Join(w.dir, entry.Name()),
				size:    info.Size(),
				modTime: info.ModTime(),
			})
		}
	}

	if totalSize <= w.maxDirSize {
		return nil
	}

	// 按时间从旧到新删除，直到目录大小回到阈值以内。
	sort.Slice(archives, func(i, j int) bool {
		return archives[i].modTime.Before(archives[j].modTime)
	})

	for _, archive := range archives {
		if totalSize <= w.maxDirSize {
			break
		}

		if err := os.Remove(archive.path); err != nil {
			return err
		}
		totalSize -= archive.size
	}

	return nil
}

func (w *rotatingWriter) nextArchiveNameLocked() (string, error) {
	// 归档名带日期和序号，避免同一天内多次轮转时重名。
	datePart := time.Now().Format("2006-01-02")
	prefix := datePart + "."
	suffix := ".log.gz"

	// 先找出当天已使用的最大序号。
	entries, err := os.ReadDir(w.dir)
	if err != nil {
		return "", err
	}

	maxSeq := -1
	for _, entry := range entries {
		name := entry.Name()
		if !strings.HasPrefix(name, prefix) || !strings.HasSuffix(name, suffix) {
			continue
		}

		seqText := strings.TrimSuffix(strings.TrimPrefix(name, prefix), suffix)
		seq, err := strconv.Atoi(seqText)
		if err != nil {
			continue
		}

		if seq > maxSeq {
			maxSeq = seq
		}
	}

	nextSeq := maxSeq + 1
	if nextSeq > 99 {
		return "", fmt.Errorf("daily log archive sequence exceeds 99: %s", datePart)
	}

	archiveName := fmt.Sprintf("%s%02d.log.gz", prefix, nextSeq)
	return filepath.Join(w.dir, archiveName), nil
}

func compressFile(sourcePath, targetPath string) error {
	// 把旧日志压缩成 gzip 归档，减少磁盘占用。
	src, err := os.Open(sourcePath)
	if err != nil {
		return err
	}
	defer src.Close()

	target, err := os.Create(targetPath)
	if err != nil {
		return err
	}
	defer target.Close()

	gz := gzip.NewWriter(target)
	defer gz.Close()

	if _, err := io.Copy(gz, src); err != nil {
		return err
	}

	return gz.Close()
}

func main() {
	// 创建轮转写入器：日志写到 app.log，文件过大时自动轮转。
	writer, err := newRotatingWriter("log/app.log")
	if err != nil {
		log.Fatal(err)
	}
	defer writer.Close()

	// MultiWriter 同时写控制台和轮转文件。
	logger := log.New(io.MultiWriter(os.Stdout, writer), "", log.Ldate|log.Ltime|log.Lshortfile)

	// 多写几条日志并加一点延时，方便观察轮转和清理过程。
	for i := 1; i <= 200; i++ {
		logger.Printf("程序运行第 %d 次，当前日志会自动轮转", i)
		time.Sleep(20 * time.Millisecond)
	}
}
```

这个示例的核心关系可以记成：

- `log.Logger` 负责发起写入
- `io.MultiWriter` 负责把写入分发给多个目标
- `rotatingWriter.Write` 负责接收写入并判断是否轮转
- 轮转时会压缩旧日志并清理过旧归档

如果你想进一步理解它，可以直接把执行链想成：`main -> log.Logger -> io.Writer -> rotatingWriter.Write`。

## 7. 一句话总结

日志这件事在 Go 里并不复杂，关键是尽早统一入口：

- 小程序可以先用 `log.Println`
- 真实项目建议封装 `logger.New`
- 需要长期运行时再加文件输出和轮转
- 如果日志量变大，就把轮转和清理策略一起考虑进去
