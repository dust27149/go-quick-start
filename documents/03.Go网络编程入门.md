# Go 网络编程入门

这份文档聚焦 Go 里最常用的网络编程能力，重点包括：

- `net/http` 基础
- 发起 HTTP 请求
- 处理 JSON
- 超时控制
- 异步网络通信
- 日志记录

这些内容覆盖了接口调用、小型服务和并发请求工具的核心基础。

版本基准：本文档以 Go 1.26.5 为基准进行介绍。

## 1. Go 为什么适合网络编程

Go 标准库自带完整网络能力，并且与并发模型结合紧密。

常见优势：

- 标准库直接可用
- Go 的轻量并发能力非常适合 I/O 并发
- 部署简单
- 性能和开发效率平衡得比较好

最常用的包：

- `net/http`
- `encoding/json`
- `io`
- `os`
- `log`
- `time`

## 2. 发起一个最简单的 HTTP GET 请求

### 定义

最基础的网络调用是发起一个 HTTP GET 请求并处理响应。

### 最小示例

```go
package main

import (
	"fmt"
	"net/http"
)

func main() {
	resp, err := http.Get("https://example.com") // 发起 GET 请求
	if err != nil {
		fmt.Println("请求失败:", err) // 请求出错就直接返回
		return
	}
	defer resp.Body.Close() // 用完后关闭响应体

	fmt.Println("状态码:", resp.StatusCode) // 打印响应状态码
}
```

### 工程注意点

- `http.Get` 发起 GET 请求
- `resp` 是响应对象
- `resp.Body` 用完后必须关闭
- 错误要先判断

### 常见坑

- 先读 `resp` 再判断 `err`。
- 忘记 `defer resp.Body.Close()` 导致连接资源泄漏。

## 3. 读取响应体

```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	resp, err := http.Get("https://example.com") // 发起 GET 请求
	if err != nil {
		fmt.Println("请求失败:", err) // 请求失败直接返回
		return
	}
	defer resp.Body.Close() // 关闭响应体

	body, err := io.ReadAll(resp.Body) // 一次性读取响应体
	if err != nil {
		fmt.Println("读取响应失败:", err) // 读取失败直接返回
		return
	}

	fmt.Println(string(body)) // 转成字符串后打印
}
```

这段代码会把响应体完整读入内存。

## 4. 自定义 HTTP 客户端和超时

### 定义

实际项目里通常会显式创建 `http.Client` 并设置超时，而不是直接使用 `http.Get`。

### 最小示例

```go
package main

import (
	"fmt"
	"net/http"
	"time"
)

func main() {
	client := http.Client{Timeout: 5 * time.Second} // 设置请求超时

	resp, err := client.Get("https://example.com") // 通过 client 发起请求
	if err != nil {
		fmt.Println("请求失败:", err) // 请求失败直接返回
		return
	}
	defer resp.Body.Close() // 关闭响应体

	fmt.Println("状态码:", resp.StatusCode) // 打印状态码
}
```

### 工程注意点

- 避免程序无限等待
- 避免下游接口卡死拖垮整个服务
- 更容易定位网络问题

### 常见坑

- 没有超时配置，问题接口会长期占用连接。
- 共享 client 时频繁新建对象，导致连接复用效果变差。

## 5. 发起 POST 请求

```go
package main

import (
	"bytes"
	"fmt"
	"net/http"
)

func main() {
	jsonBody := []byte(`{"name":"Tom","age":20}`) // 请求体内容

	resp, err := http.Post(
		"https://jsonplaceholder.typicode.com/posts", // 公开测试接口
		"application/json", // Content-Type
		bytes.NewBuffer(jsonBody), // 请求体
	)
	if err != nil {
		fmt.Println("请求失败:", err) // 请求失败直接返回
		return
	}
	defer resp.Body.Close() // 关闭响应体

	fmt.Println("状态码:", resp.StatusCode) // 打印状态码
}
```

## 6. 处理 JSON

JSON 是网络编程中最常见的数据格式之一。

### JSON 反序列化

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	Name string `json:"name"`
	Age  int    `json:"age"`
}

func main() {
	data := []byte(`{"name":"Alice","age":25}`) // 模拟 JSON 数据

	var user User // 用结构体接收解析结果
	err := json.Unmarshal(data, &user) // JSON 反序列化
	if err != nil {
		fmt.Println("解析失败:", err) // 解析失败直接返回
		return
	}

	fmt.Println(user.Name, user.Age) // 打印解析结果
}
```

### JSON 序列化

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	Name string `json:"name"`
	Age  int    `json:"age"`
}

func main() {
	user := User{Name: "Alice", Age: 25} // 待编码的结构体

	body, err := json.Marshal(user) // JSON 序列化
	if err != nil {
		fmt.Println("编码失败:", err) // 编码失败直接返回
		return
	}

	fmt.Println(string(body)) // 输出 JSON 字符串
}
```

### 从 HTTP 响应中解析 JSON

```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"time"
)

type APIResponse struct {
	UserID    int    `json:"userId"`
	ID        int    `json:"id"`
	Title     string `json:"title"`
	Completed bool   `json:"completed"`
}

func main() {
	client := http.Client{Timeout: 5 * time.Second} // 设置超时
	resp, err := client.Get("https://jsonplaceholder.typicode.com/todos/1") // 发起请求
	if err != nil {
		fmt.Println("请求失败:", err) // 请求失败直接返回
		return
	}
	defer resp.Body.Close() // 关闭响应体

	if resp.StatusCode != http.StatusOK {
		fmt.Println("请求失败, 状态码:", resp.StatusCode) // 状态码不为 200，直接返回
		return
	}
	var result APIResponse // 用于接收解析后的 JSON
	err = json.NewDecoder(resp.Body).Decode(&result) // 从响应体直接解码
	if err != nil {
		fmt.Println("JSON 解析失败:", err) // 解析失败直接返回
		return
	}

	fmt.Printf("请求成功(%d), UserID: %d, ID: %d, Title: %s, Completed: %t\n", resp.StatusCode, result.UserID, result.ID, result.Title, result.Completed) // 打印字段
}
```

`json.NewDecoder` 适合直接处理 HTTP 响应流。

## 7. 异步网络通信

### 定义

Go 里异步网络通信的常见实现方式：

- 每个网络请求放进一个 goroutine
- 用 channel 汇总结果
- 用超时和日志保护执行过程

### 最小示例

```go
package main

import (
	"fmt"
	"net/http"
	"time"
)

func fetch(url string, ch chan<- string) {
	client := http.Client{Timeout: 3 * time.Second} // 每个请求都设置超时
	resp, err := client.Get(url) // 发起请求
	if err != nil {
		ch <- fmt.Sprintf("%s 请求失败: %v", url, err) // 把失败结果发回主流程
		return
	}
	defer resp.Body.Close() // 关闭响应体

	ch <- fmt.Sprintf("%s 状态码: %d", url, resp.StatusCode) // 回传状态码
}

func main() {
	urls := []string{
		"https://example.com",
		"https://golang.org",
	}

	resultCh := make(chan string) // 汇总各个请求结果的通道

	for _, url := range urls {
		go fetch(url, resultCh) // 每个 URL 启动一个 goroutine
	}

	for range urls {
		fmt.Println(<-resultCh) // 依次读取结果
	}
}
```

### 工程注意点

- 批量检查网站状态
- 同时调用多个 API
- 聚合多个下游服务结果

### 常见坑

- 结果接收次数与请求数不一致导致阻塞。
- 只打印成功路径，不记录失败上下文。

## 8. select 配合网络超时

除了客户端超时，程序还可以在业务逻辑层做更细粒度控制。

```go
package main

import (
	"fmt"
	"time"
)

func main() {
	resultCh := make(chan string) // 结果通道

	go func() {
		time.Sleep(3 * time.Second) // 模拟耗时任务
		resultCh <- "请求完成" // 任务完成后发消息
	}()

	select {
	case msg := <-resultCh: // 先等结果通道
		fmt.Println(msg)
	case <-time.After(1 * time.Second): // 超过 1 秒就超时
		fmt.Println("业务超时")
	}
}
```

这类写法常用于保护整体请求时延。

## 9. 写一个最简单的 HTTP 服务

Go 既适合写客户端，也适合写服务端。

```go
package main

import (
	"fmt"
	"net/http"
)

func helloHandler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "Hello, Go HTTP Server") // 写回响应内容
}

func main() {
	http.HandleFunc("/hello", helloHandler) // 注册路由
	fmt.Println("server listening on :8080")
	http.ListenAndServe(":8080", nil) // 启动 HTTP 服务
}
```

访问地址：

```text
http://localhost:8080/hello
```

### 返回 JSON

```go
package main

import (
	"encoding/json"
	"net/http"
)

type Response struct {
	Message string `json:"message"`
}

func helloHandler(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json") // 声明返回 JSON
	json.NewEncoder(w).Encode(Response{Message: "hello"}) // 编码并返回 JSON
}

func main() {
	http.HandleFunc("/hello", helloHandler) // 注册路由
	http.ListenAndServe(":8080", nil) // 启动服务
}
```

## 10. 基础日志输出

### 定义

网络程序建议使用 `log` 包，而不是仅依赖 `fmt.Println`。

### 最小示例

```go
package main

import "log"

func main() {
	log.Println("程序启动")
}
```

### 工程注意点

- 文件日志建议使用追加模式，避免覆盖历史记录。
- 推荐控制台 + 文件双写，便于本地调试和线上排障。

### 写入日志文件

```go
package main

import (
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile("app.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)
	if err != nil {
		log.Fatal(err) // 打开失败直接退出
	}
	defer file.Close() // 程序结束时关闭文件

	logger := log.New(file, "INFO: ", log.Ldate|log.Ltime|log.Lshortfile) // 写入文件日志
	logger.Println("程序启动")
}
```

### 同时输出到控制台和文件

```go
package main

import (
	"io"
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile("app.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)
	if err != nil {
		log.Fatal(err) // 打开失败直接退出
	}
	defer file.Close() // 程序结束时关闭文件

	writer := io.MultiWriter(os.Stdout, file) // 同时写控制台和文件
	logger := log.New(writer, "INFO: ", log.Ldate|log.Ltime) // 统一日志格式

	logger.Println("服务启动")
}
```

### 常见坑

	- 打开文件后忘记关闭。
	- 日志缺少 URL、状态码、错误堆栈等关键字段。

## 11. 网络程序里应该记录什么日志

入门阶段建议至少记录这些信息：

- 程序启动和退出
- 请求开始和结束
- URL、方法、状态码
- 超时、失败、重试
- 关键结果汇总

例如：

```go
logger.Printf("开始请求: %s", url) // 请求开始
logger.Printf("请求完成: %s, status=%d", url, resp.StatusCode) // 请求完成
logger.Printf("请求失败: %s, err=%v", url, err) // 请求失败
```

## 12. 一个综合例子：并发请求加日志

```go
package main

import (
	"fmt"
	"io"
	"log"
	"net/http"
	"os"
	"time"
)

func fetch(url string, logger *log.Logger, resultCh chan<- string) {
	logger.Printf("开始请求: %s", url) // 记录开始时间和目标 URL

	client := http.Client{Timeout: 5 * time.Second} // 超时控制
	resp, err := client.Get(url) // 发起请求
	if err != nil {
		logger.Printf("请求失败 %s: %v", url, err) // 记录错误
		resultCh <- fmt.Sprintf("%s 失败", url) // 失败结果回传
		return
	}
	defer resp.Body.Close() // 关闭响应体

	logger.Printf("请求成功: %s, status=%d", url, resp.StatusCode) // 记录成功
	resultCh <- fmt.Sprintf("%s -> %d", url, resp.StatusCode) // 回传状态码
}

func main() {
	file, err := os.OpenFile("app.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)
	if err != nil {
		log.Fatal(err) // 打开文件失败直接退出
	}
	defer file.Close() // 程序结束时关闭文件

	logger := log.New(io.MultiWriter(os.Stdout, file), "INFO: ", log.Ldate|log.Ltime) // 同时写控制台和文件

	urls := []string{ // 需要并发请求的网址列表
		"https://example.com",
		"https://golang.org",
	}

	resultCh := make(chan string) // 汇总结果的通道

	for _, url := range urls {
		go fetch(url, logger, resultCh) // 每个 URL 启动一个 goroutine
	}

	for range urls {
		logger.Println("收到结果:", <-resultCh) // 依次接收结果
	}

	logger.Println("全部请求完成") // 最终汇总日志
}
```

这个例子覆盖了：

- 并发请求
- HTTP 客户端超时
- 结果汇总
- 控制台和文件双写日志

## 13. 初学者常见问题

### 1. 为什么请求一直卡住

通常是没设置超时，或者下游接口本身阻塞。

### 2. 为什么响应体读取失败

可能原因：

- 网络请求本身失败
- 响应体为空
- 没有先判断 `err`
- 重复读取已消费的响应流

### 3. 为什么 JSON 解码报错

常见原因：

- 结构体字段名或 tag 不匹配
- 服务端返回的不是预期 JSON
- 字段类型不一致

### 4. 为什么日志文件没有内容

常见原因：

- 文件没打开成功
- 程序还没写入就退出
- 写入目标不是你预期目录

## 14. 建议练习项目

你可以按这个顺序练：

1. 请求一个网页并打印状态码
2. 读取响应体并打印前几行
3. 请求一个 JSON API 并解析字段
4. 写一个 POST 请求发送 JSON 数据
5. 并发请求多个网站
6. 为请求程序加日志文件输出
7. 写一个本地 HTTP 服务返回 JSON

## 15. 总结

Go 网络编程的入门主线：

- 用 `net/http` 发请求和写服务
- 用 `encoding/json` 处理接口数据
- 用 goroutine 和 channel 做异步并发
- 用 `time` 做超时控制
- 用 `log` 和文件输出记录关键过程

掌握这条主线后，你就可以写出一批实用小程序，例如：

- 网站状态探测器
- 接口聚合工具
- 简单爬虫
- 本地 API 服务
- 带日志的并发任务程序
