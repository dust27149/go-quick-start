# Go 语言基础入门教程

这份教程面向刚开始接触 Go 的开发者，尤其适合有 Java 编程经验、希望快速上手 Go 的读者。目标不是一次讲完所有语法，而是让你能尽快写出可运行的程序，并掌握 Go 在并发、网络和工程化中的常用能力。

版本基准：本文档以 Go 1.26.5 为基准进行介绍。

这份教程还会额外介绍这些常见主题：

- 包和模块管理
- 日志文件输出

示例代码复制运行提示：

- 带完整 `package main`、`import`、`func main()` 的代码块可以直接复制运行。
- 只有几行的代码块通常是语法片段，用来聚焦讲解单个知识点。如果你想把语法片段直接跑起来，可以先套一个最小 `main` 模板。

## 1. Go 是什么

Go 是一门静态类型、编译型语言，语法简单，标准库完整，并发模型清晰，适合写：

- 后端服务
- 命令行工具
Go 的典型特点：

- 语法少，学习曲线相对平缓
- 编译速度快
- 内置并发支持
- 标准库质量高
- 部署简单，通常直接生成单个可执行文件

如果你来自 Java，可以先这样对照理解：

- Go 接口更强调“行为约束”，且常在使用侧定义。
- `struct` 类似“只含字段的数据类骨架”，行为通常由方法补充。
- 错误处理以 `error` 返回值为主，而不是日常依赖异常流。
- Go 没有 `public`、`private` 这类关键字，而是直接用首字母大小写区分对外暴露还是仅内部使用：
  - 首字母大写：表示可导出，其他包可以访问，例如 `fmt.Println`、`http.Client`。
  - 首字母小写：表示仅包内可见，其他包不能直接访问。

## 2. Windows 和 Linux 安装 Go（基于 Go 1.26.5）

下载地址：[https://go.dev/dl/](https://go.dev/dl/)

### Windows 安装

- 访问 Go 官方下载页，下载 `go1.26.5.windows-amd64.msi`（64 位 Windows 常用）。
- 双击安装包，按默认选项安装。
- 打开新终端，执行：

```powershell
go version
```

- 若输出包含 `go version go1.26.5`，说明安装成功。

### Linux 安装

- 下载 Go 1.26.5 压缩包（例如 `go1.26.5.linux-amd64.tar.gz`）。
- 删除旧版本并解压到 `/usr/local`：

```bash
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf go1.26.5.linux-amd64.tar.gz
```

- 配置环境变量（写入 `~/.bashrc` 或 `~/.zshrc`）：

```bash
export PATH=$PATH:/usr/local/go/bin
```

- 重新加载配置并验证：

```bash
source ~/.bashrc
go version
```

### 常见问题

- 终端提示找不到 `go`：通常是 PATH 未生效，重开终端或检查环境变量。
- `go version` 不是 1.26.5：系统里可能有旧版 Go，优先检查 PATH 顺序。

## 3. Go 常用命令速查（基于 Go 1.26.5）

### 项目模块初始化
初始化 Go 模块，生成 `go.mod` 文件：
```powershell
# your-module-name替换为项目名或仓库路径，建议使用字母、数字、`-`、`/`、`.` 等常见字符。
go mod init your-module-name 
```

### 运行与构建

- 运行单文件（适合临时实验和独立示例）

```powershell
go run xx.go
```

- 运行当前目录整个包（适合多文件协作的项目代码）

```powershell
go run .
```
注意：若在项目中执行 `go run .` 时，出现 `cannot find main module` ，先执行项目初始化，再执行 `go run .`

- 编译当前目录包（在项目开发场景下使用）

```powershell
go build .
```

### 模块与依赖

- 初始化模块（首次创建项目时）

```powershell
go mod init your-module-name
```

- 安装/升级当前项目依赖（会更新 `go.mod`）

```powershell
go get github.com/sirupsen/logrus
```

- 整理依赖（清理未使用项并补齐缺失项）

```powershell
go mod tidy
```

- 安装命令行工具（用于开发辅助）

```powershell
go install golang.org/x/tools/gopls@latest # 安装 Go 语言服务器，提供代码补全、跳转和报错提示
go install golang.org/x/tools/cmd/goimports@latest # 安装导入整理工具，自动补全、删除并格式化 import
```

### 环境配置

- 查看当前 Go 环境

```powershell
go env
```

- 设置国内常用代理

```powershell
go env -w GOPROXY=https://goproxy.cn,direct
```

- 恢复官方默认代理

```powershell
go env -w GOPROXY=https://proxy.golang.org,direct
```

## 4. 包和模块管理

### 定义

先建立一个最重要的认识：Go 代码通常按“文件 -> 包（package）-> 模块（module）-> 项目”来组织。

- 文件：一个 `.go` 源文件。
- 包（package）：一组同目录、同 `package` 名的 Go 文件。
- 模块（module）：一个带 `go.mod` 的项目边界，用来管理依赖。

Go Modules 是依赖管理与构建边界的基础。

它主要解决两个问题：

- 依赖版本不可控，团队成员环境不一致。
- 项目边界不清晰，构建和发布不可重复。

任何非一次性脚本的 Go 项目，都应尽早进行项目初始化生成 `go.mod`。

定期整理依赖，清理未使用项并补齐缺失项。模块文件长期不整理，依赖状态会逐步失真。

### 包（package）是什么

包可以理解成“代码分组单位”。把一组职责相关的函数、类型、变量放到同一个包里，便于复用和维护。

例如：

```go
package config
```

这表示当前文件属于 `config` 包。

初学阶段先记住两个规则：

- 同一个目录下的 Go 文件，通常应属于同一个包。
- 包名通常简短、直接，常和目录名保持一致，例如 `config`、`logger`、`client`。

Go 不要求像 Java 那样把 `struct`、`func`、方法等强制拆到不同文件里。只要它们属于同一个包，就可以放在同一个 `.go` 文件中。是否拆文件，主要取决于可读性和维护成本，而不是语法要求。Go 更强调“按包组织代码”，不是“按类型强制分文件”。

### 模块（module）是什么

模块可以理解成“项目边界 + 依赖边界”。

当你执行：

```powershell
go mod init your-module-name
```

Go 会在项目根目录生成 `go.mod`。从这一刻开始：

- 当前项目有了明确的模块名。
- 依赖版本会记录在模块文件中。
- 导入你自己项目里的包时，也会以模块名为起点。

例如模块名是：

```text
github.com/yourname/demo
```

那么项目里的 `config` 包可以这样导入：

```go
import "github.com/yourname/demo/config"
```

### `package main` 是什么

`package main` 表示“这个包会编译成可执行程序”。

最常见的入口文件就是：

```go
package main

func main() {
	// 程序入口
}
```

这里有两个条件：

- 包名必须是 `main`
- 必须存在 `func main()` 作为程序入口

如果缺少其中任何一个，它就不是一个可直接运行的程序包。

### `package xxx` 是什么

除了 `package main`，其他包通常都是“可复用代码包”，例如：

```go
package logger
```

这类包通常：

- 不直接作为程序入口运行
- 用来提供函数、结构体、方法、工具逻辑
- 由 `main` 包或其他包导入后使用

例如：

```go
package logger

func Init() {
	// 初始化日志
}
```

然后在 `main.go` 里导入并调用：

```go
import "github.com/yourname/demo/internal/logger"
```

### `internal` 是什么

`internal` 是 Go 约定里一个很重要的目录名，用来放“只给当前项目内部使用的代码”。

你可以先把它理解成“项目内部实现细节区”。

放在 `internal/` 下的包：

- 可以被当前项目内部导入
- 不能被项目外部随意导入

这样做的好处是：

- 避免把还不稳定的实现细节暴露给外部
- 帮团队明确哪些代码是内部实现，哪些代码是对外能力

入门项目里，日志初始化、HTTP 客户端、worker 等都很适合放在 `internal/` 下。

### 建议目录结构

入门阶段可以先按下面的结构组织项目：

```text
your-project-name/
	go.mod
	main.go
	config/
		config.go
	internal/
		client/
			http_client.go
		logger/
			logger.go
		worker/
			worker.go
```

各部分用途：

- `your-project-name/`：项目根目录，也是模块根目录。
- `go.mod`：记录模块名和依赖版本，是 Go Modules 的核心文件。
- `main.go`：程序入口文件，通常属于 `package main`，负责组装配置、日志、客户端和业务流程。
- `config/config.go`：集中定义配置结构、默认值和配置加载逻辑。
- `config/`：通常使用 `package config`，放配置相关代码。
- `internal/client/http_client.go`：通常使用 `package client`，封装 HTTP 请求逻辑，统一超时、请求头和后续扩展。
- `internal/logger/logger.go`：通常使用 `package logger`，统一初始化日志，避免日志配置散落各处。
- `internal/worker/worker.go`：通常使用 `package worker`，放并发任务、批处理逻辑或业务执行单元。

目录设计建议：

- 小项目一开始不必拆太细，但至少要把入口、配置、日志和业务逻辑分开。
- `internal/` 适合放只给当前项目内部使用的代码，避免对外暴露过多实现细节。
- 当项目还很小时，也可以先只保留 `main.go` 和 `go.mod`，后面再逐步拆分目录。

### 初学者最容易混淆的点

- `package` 是代码分组单位，`module` 是项目与依赖边界，它们不是同一个概念。
- `package main` 是可执行程序入口包，`package config`、`package logger` 这类通常是功能包。
- 导入路径看模块名 + 目录路径，不是只看包名。
- `internal/` 不是关键字，而是 Go 识别的特殊目录约定。

```go
package main

import "fmt"

func main() {

```

代码说明：

- `package main` 表示这是一个可执行程序
- `import "fmt"` 引入标准库里的格式化输出包
- `func main()` 是程序入口
- `fmt.Println` 用于打印一行内容

运行和构建命令请直接参考第 3 章“Go 常用命令速查”，这里聚焦程序结构本身。

## 6. 常见小符号

Go 里有一些很常见的小符号，入门时先认识它们，后面的章节会轻松很多。

### `_`：忽略不需要的值

`_` 叫作空白标识符，表示这个值我不需要。

例如：

```go
urls := []string{"https://example.com", "https://golang.org"}

for _, url := range urls {
	fmt.Println(url)
}
```

它经常出现在两个地方：

- 需要忽略函数返回值时
- 遍历 `range` 时，暂时不需要下标时

什么时候用：当你拿到了值，但暂时不想处理它。

### `:=`：快速声明变量

```go
name := "Tom"
```

它表示“声明一个变量并赋值”。初学阶段可以先记住：

- 只能在函数内部使用
- Go 会自动推导变量类型

什么时候用：当你在函数里想快速创建一个新变量时。

### `&`：取地址

```go
value := 10
fmt.Println(&value)
```

`&value` 表示取出变量 `value` 的地址。后面讲指针和输入时会继续用到。

什么时候用：当你需要把变量的位置传给函数时。

### `*`：取值或表示指针

```go
var p *int
```

这里的 `*int` 表示“一个指向 int 的指针”。当 `*` 用在变量前面时，例如 `*p`，表示取出这个指针指向的值。

什么时候用：当你要声明指针，或者从指针里取出值时。

### `|`：把多个选项合在一起

```go
os.O_CREATE | os.O_WRONLY | os.O_APPEND
```

它常用于把多个选项一起传给函数。你现在可以先把它理解成“同时开启这些选项”。

什么时候用：当一个参数需要同时打开多个选项时。


## 7. Go 关键字和作用

Go 的关键字数量不多，但有些用法和其他语言差别很大。先认识这些高频关键字，后面读代码会顺畅很多。

- `func`：定义函数。和很多语言类似，但 Go 里函数签名里的类型位置更固定。
- `var`：声明变量。Go 允许 `var name string` 这种“名字在前、类型在后”的写法。
- `const`：声明常量。Go 的常量不能用 `:=`。
- `type`：定义新类型，例如 `type Person struct { ... }`。
- `struct`：定义结构体，用来组合多个字段。
- `if` / `else`：条件分支。Go 的 `if` 不需要括号。
- `for`：循环。Go 没有 `while` 关键字，循环统一用 `for`。
- `range`：遍历集合（切片、数组、map、字符串）。
- `switch`：多分支判断，通常比多层 `if / else if` 更清晰。
- `go`：启动 goroutine，这是 Go 并发模型里非常有代表性的关键字。
- `chan`：声明通道类型，用于 goroutine 之间通信。
- `select`：同时等待多个 channel 操作。
- `defer`：在函数返回前执行，常用于 `defer file.Close()` 做资源清理。
- `return`：函数返回。

和其他语言差异较大的点可以先记住这几个：

- Go 用 `for` 统一循环，不提供独立的 `while` 关键字。
- Go 不支持三元运算符（`A ? B : C`），通常使用 `if / else`。
- Go 的并发是语言内建能力（`go`、`chan`、`select`），不是只靠外部库。
- Go 强调显式错误处理（`if err != nil`），而不是把普通错误都交给异常机制。

## 8. 变量、常量和基本类型

### 变量

变量用于保存会变化的数据。

变量常见声明方式：

```go
var a int = 10
var b = 20 // Go 会自动推导类型为 int
c := 30 // 只能在函数内部使用，Go 会自动推导类型为 int
```

变量说明：

- `:=` 只能在函数内部使用
- Go 会自动推导变量类型
- 未使用的局部变量会直接导致编译报错

### 常量

`const` 用来定义在运行期间不会变化的值，比如圆周率、站点名、版本号等。

```go
const site = "golang.org" // 自动推导类型为 string
const pi float64 = 3.14159
```

和变量相比，常量可以先这样理解：

- 变量用 `var` 或 `:=`，值可以修改
- 常量用 `const`，定义后不能再赋新值
- `const` 不能使用 `:=`

什么时候优先用常量：

- 业务里不会变的固定值
- 需要统一管理的标识字符串
- 避免“魔法数字/魔法字符串”散落在代码里

### 基本类型

Go 里常用的基本类型有：

- `int`
- `float64`
- `bool`
- `string`

### `nil` 是什么

`nil` 可以理解为“空引用值”，但它不是所有类型都能用。

适用类型（常见）：

- 指针（`*T`）
- 切片（`[]T`）
- map（`map[K]V`）
- channel（`chan T`）
- 接口（`interface{}`）
- 函数类型（`func(...) ...`）

`nil` 和 `0`、`""`、`false` 不同：

- `0` 是数字零值
- `""` 是字符串零值
- `false` 是布尔零值
- `nil` 是引用类类型的零值

示例：

```go
var p *int // 声明一个指针类型变量 p，但还没有指向任何有效的内存地址
fmt.Println(p == nil) // true，因为指针 p 还没有指向任何有效的内存地址

var s []int // 声明一个切片类型变量 s，但还没有分配底层数组
fmt.Println(s == nil) // true，因为切片 s 还没有分配底层数组

var m map[string]int // 声明一个 map 类型变量 m，但还没有分配内存
fmt.Println(m == nil) // true，因为 map m 还没有分配内存
```

常见坑：

- `nil map` 可以读，但不能直接写。写入会导致运行时错误。

```go
var m map[string]int
fmt.Println(m["Tom"]) // 读：不会导致运行时错误，返回零值

// m["Tom"] = 20 // 写入会导致运行时错误：assignment to entry in nil map
```

- 需要写入 map 时，先使用内建函数 `make` 初始化：

```go
m := make(map[string]int)
m["Tom"] = 20
```

## 9. 数组、切片和 map

### 数组

数组声明格式：

- `[数组长度]数组类型{元素1, 元素2, ...}`

例如：

```go
arr := [3]int{1, 2, 3}
fmt.Println(arr)
```

数组的长度固定，声明时就写死了。数组是值类型，赋值或传参时通常会复制整个数组，所以适合长度明确、不会经常变化的场景。

### 切片

切片声明格式：

- `[]切片元素类型{元素1, 元素2, ...}`

例如：

切片比数组更常用。

```go
nums := []int{1, 2, 3}
nums = append(nums, 4)
fmt.Println(nums)
```

切片的长度可以变化，更像是一个指向底层数组的“窗口”。切片本身记录了底层数据的位置、长度和容量，所以复制切片后，多个切片通常会共享同一份底层数据，修改其中一个时，另一个也可能看到变化。

初学阶段可以先这样理解：

- 需要固定长度时，用数组。
- 大多数业务代码里，更常用切片。

### map

map 声明格式：

- `map[key类型]value类型{key1: value1, key2: value2, ...}`

例如：

```go
ages := map[string]int{
	"Tom":  20,
	"Lucy": 22,
}

fmt.Println(ages["Tom"])
```

判断 key 是否存在：

```go
age, ok := ages["Tom"]
if ok {
	fmt.Println("存在", age)
} else {
	fmt.Println("不存在")
}
```

## 10. 条件判断和循环

### if

```go
score := 85

if score >= 90 {
	fmt.Println("优秀")
} else if score >= 60 {
	fmt.Println("及格")
} else {
	fmt.Println("不及格")
}
```

Go 的 `if` 不需要小括号。

### switch

`switch` 用于多分支判断，语义上通常比很多 `if / else if` 更清晰。

```go
day := 3

switch day {
case 1:
	fmt.Println("周一")
case 2:
	fmt.Println("周二")
case 3:
	fmt.Println("周三")
default:
	fmt.Println("其他")
}
```

说明：

- `switch` 后面的表达式不需要小括号。
- Go 的 `case` 默认不会自动贯穿到下一个分支（不需要默认写 `break`）。
- `default` 分支是可选的，用于兜底处理。

### for

Go 里只有一种循环关键字：`for`

```go
for i := 0; i < 5; i++ {
	fmt.Println(i)
}
```

它也可以当作 while 使用：

```go
i := 0
for i < 5 {
	fmt.Println(i)
	i++
}
```

Go 的 `for` 条件同样不需要小括号。

### range

`range` 常用来遍历切片、数组、map 或字符串。你可以先把它理解成“把一组数据里的每一项依次取出来”。

最常见的写法是遍历切片或数组：
* 取出下标和元素：
```go
urls := []string{"https://example.com", "https://golang.org"}

for index, url := range urls {
	fmt.Println(index, url)
}
```

* 只取出下标：
```go
urls := []string{"https://example.com", "https://golang.org"}
for index := range urls {
	fmt.Println(index)
}
```

* 只取出元素：
```go
urls := []string{"https://example.com", "https://golang.org"}
// 对于不需要的值，可以用 `_` 忽略
for _, url := range urls {
	fmt.Println(url)
}
```

它也可以用来遍历 `map`：

* 取出 key 和 value：
```go
ages := map[string]int{"Tom": 20, "Lucy": 22}
for key, value := range ages {
	fmt.Println(key, value)
}
```

* 只取出 key：
```go
ages := map[string]int{"Tom": 20, "Lucy": 22}
for key := range ages {
	fmt.Println(key)
}
```

* 只取出 value：
```go
ages := map[string]int{"Tom": 20, "Lucy": 22}
// 对于不需要的值，可以用 `_` 忽略
for _, value := range ages {
	fmt.Println(value)
}
```

它还可以遍历字符串，初学阶段先知道有这个用法即可。

## 11. 函数
### 函数声明
```go
package main

import "fmt"

func add(a int, b int) int {
	return a + b
}

func main() {
	result := add(3, 5)
	fmt.Println(result)
}
```

这段函数声明可以拆开来看：

- `func` 表示这是一个函数
- `add` 是函数名
- `a` 和 `b` 是形参名，也就是函数接收的两个输入参数
- `int` 是形参类型，表示这两个参数都是整数
- 最后那个 `int` 是返回值类型，表示这个函数返回一个整数

你也可以把它记成这个格式：`func 函数名(形参名 形参类型, ...) 返回值类型`

### 多个返回值

Go 支持多个返回值。如果有多个返回值，返回值类型写在一对括号里。

```go
func swap(a, b int) (int, int) {
	return b, a
}
```

不能只用一个变量直接接多返回值函数；如果只想要其中一部分结果，需要用多个变量接收，并用 `_` 忽略不需要的值。

```go
first, _ := swap(1, 2)
fmt.Println(first)
```
### 匿名函数
`func() { ... }()` 是匿名函数，最后面的 `()` 表示定义后立刻调用。

例如：

```go
func() {
	fmt.Println("匿名函数")
}()
```

匿名函数也可以带参数并立刻调用：

```go
func(n int) {
	fmt.Println("参数 n =", n)
}(10) // 这里的 10 会传给匿名函数的 n
```

这种写法在 goroutine 里很常见。

### go内建函数 `make()` 和 `new()` 的区别

这两个都能“创建东西”，但用途不同：

- `new(T)`：分配一个 `T` 类型的零值，并返回 `*T`（指针）。
- `make(T, ...)`：只用于 `slice`、`map`、`channel`，返回的是类型本身（不是指针），并完成内部初始化。

`new` 示例：

```go
p := new(int)  // p 的类型是 *int，指向一个值为 0 的 int
*p = 10
fmt.Println(*p) // 10
```

`make` 示例：

```go
s := make([]int, 3)        // 长度为 3 的切片
m := make(map[string]int)  // 可直接写入的 map

m["Tom"] = 20
s[0] = 1
```

常见坑：

- `new(map[string]int)` 得到的是 `*map[string]int`，且底层 map 仍是空引用值，不能直接写入键值。
- 需要“可直接使用”的 map/slice 等类型时，优先用 `make`。

## 12. struct 和方法

### struct
`struct` 可以理解成一个自定义的数据类型，用来把多个相关字段放在一起。比如一个人可以有名字、年龄，这些信息就适合放进一个 `struct` 里。

```go
type Person struct {
	Name string
	Age  int
}
```

这个结构可以拆开来看：

- `type Person` 表示定义一个名叫 `Person` 的新类型
- `struct` 表示这个新类型是一个结构体
- `Name string` 表示这个结构体里有一个名为 `Name` 的字段，类型是 `string`
- `Age int` 表示这个结构体里有一个名为 `Age` 的字段，类型是 `int`

你可以把 `struct` 理解成“把多个字段装进一个盒子里”，字段后面的类型决定了这个盒子里每一项能放什么数据。

使用：

```go
p := Person{Name: "Alice", Age: 23}
fmt.Println(p.Name, p.Age)
```

### 引用其他包的结构体并初始化实例

例如，引用 `http` 包并初始化 `Client` 结构体：

```go
package main

import (
	"fmt"
	"net/http"
	"time"
)

func main() {
	// 只设置 Timeout 字段，其他字段使用默认零值。
	client := http.Client{Timeout: 3 * time.Second}
	fmt.Println("client timeout:", client.Timeout)
}
```

其中：

- `http` 是包名，`Client` 是这个包里定义的结构体类型，合起来写成 `http.Client`。
- `{Timeout: 3 * time.Second}` 是按字段名初始化（keyed literal）。
- 这类写法常用于“只关心少数字段”的场景：只给需要的字段赋值，其他字段保持默认零值。

可以把它理解成：创建一个 `http.Client` 实例，并只把 `Timeout` 设为 3 秒。

通用模式是：`包名.结构体类型{字段1: 值1, 字段2: 值2}`。

### 方法
方法是绑定在某个类型上的函数。它通常用来表示“这个数据能做什么”，比如一个 `Person` 可以有“打招呼”的方法。

```go
type Person struct {
	Name string
}

func (p Person) SayHello() {
	fmt.Println("你好，我是", p.Name)
}
```

函数和方法的区别可以先简单记成这样：

- 函数不依赖某个具体类型，直接写 `func 函数名(...)` 就可以
- 方法要绑定到某个类型上，写法里会有接收者，比如 `func (p Person) SayHello()`
- 调用方式也不一样，函数直接调用，方法通常通过对象调用

如果你看到一个函数前面带了 `(p Person)` 这一段，就可以先把它理解成“这是 `Person` 的方法”

调用：

```go
p := Person{Name: "Alice"}
p.SayHello()
```

## 13. 指针

Go 有指针，但没有 C 那样复杂的指针运算。初学阶段只要会传地址和改值就够了。

```go
package main

import "fmt"

func changeValue(n *int) {
	*n = 100 // 通过指针修改原变量的值
}

func main() {
	a := 10
	changeValue(&a) // 传入 a 的地址
	fmt.Println(a)
}
```

说明：

- `&a` 表示取地址
- `*n` 表示取出该地址对应的值

## 14. 输入输出

```go
package main

import "fmt"

func main() {
	var name string
	fmt.Print("请输入你的名字: ")
	fmt.Scan(&name)
	fmt.Println("你好，", name)
}
```

说明：

- `Print` 不自动换行
- `Println` 自动换行
- `Scan` 用来读取输入
- `&name` 表示把 `name` 的地址传给 `Scan`
- `*` 表示取出指针指向的值

如果你已经学过前面的指针章节，就可以把 `&name` 理解成“把变量放到输入函数能写入的位置”。

## 15. 错误处理

Go 里常规错误处理依赖 `error`，而不是大量使用异常。

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	file, err := os.Open("data.txt") // 尝试打开文件，若成功返回文件对象，若失败会返回错误
	// 对错误进行处理
	if err != nil {
		fmt.Println("打开文件失败:", err)
		return
	}
	defer file.Close()

	fmt.Println("文件打开成功")
}
```

基础规则：

- 先判断 `err != nil`
- 错误尽早返回
- 成功路径保持清晰

### `defer` 执行时机

`defer` 注册的调用会在“当前函数返回前”执行，不是在当前代码块（如 `if`、`for`）结束时执行。

如果有多个 `defer`，执行顺序是后进先出（LIFO）。

```go
package main

import "fmt"

func main() {
	defer fmt.Println("defer-1")
	defer fmt.Println("defer-2")

	fmt.Println("main body")
}
```

输出顺序：

```text
main body
defer-2
defer-1
```

这也是为什么文件操作常写成 `defer file.Close()`：无论函数中间走到哪里返回，都会在返回前执行关闭动作。

## 16. 日志输出

### 定义

日志用于记录程序关键过程，便于排障与回溯。生产环境不建议只依赖 `fmt.Println`。

它主要解决两个问题：

- 出问题后没有足够上下文定位原因。
- 程序运行过程不可观测，难以复盘。

适用场景：服务启动、关键业务步骤、错误分支、外部依赖调用前后。

### 最小示例

```go
package main

import "log"

func main() {
	log.Println("程序启动")
}
```

### 工程注意点

- `log.Println` 默认包含时间信息。
- 文件日志建议使用 `os.OpenFile(..., os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0666)`。
- 线上常用 `io.MultiWriter` 同时输出到控制台和文件。

输出到日志文件：

```go
package main

import (
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile(
		"app.log",                         // 文件名：日志输出到当前目录下 app.log
		os.O_CREATE|os.O_WRONLY|os.O_APPEND, // 打开方式：不存在则创建、只写、追加写入
		0666,                               // 文件权限：rw-rw-rw-（实际权限还会受 umask 影响）
	)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	logger := log.New(
		file,                            // 输出目标：写入日志文件
		"INFO: ",                       // 日志前缀：每条日志前加上 INFO:
		log.Ldate|log.Ltime|log.Lshortfile, // 日志格式：日期 + 时间 + 短文件名:行号
	)
	logger.Println("程序启动成功")
}
```

同时输出到控制台和文件：

```go
package main

import (
	"io"
	"log"
	"os"
)

func main() {
	file, err := os.OpenFile(
		"app.log",                         // 文件名：日志输出到当前目录下 app.log
		os.O_CREATE|os.O_WRONLY|os.O_APPEND, // 打开方式：不存在则创建、只写、追加写入
		0666,                               // 文件权限：rw-rw-rw-（实际权限还会受 umask 影响）
	)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	writer := io.MultiWriter(
		os.Stdout, // 目标 1：标准输出（控制台）
		file,      // 目标 2：日志文件
	)
	logger := log.New(
		writer,              // 输出目标：同时写到控制台和文件
		"INFO: ",           // 日志前缀：每条日志前加上 INFO:
		log.Ldate|log.Ltime, // 日志格式：日期 + 时间
	)

	logger.Println("程序启动")
	logger.Println("日志同时写入控制台和文件")
}
```

### 常见坑

- 打开文件后忘记 `defer file.Close()`。
- 日志只打成功路径，失败路径缺少上下文。
- 日志粒度过粗，无法定位具体请求或阶段。

## 17. 初学者常见坑

### 1. 忘记关闭文件

打开文件后通常要：

```go
defer file.Close()
```

### 2. 忽略 error

Go 的很多标准库调用都会返回 `error`，忽略它往往会带来难查问题。

## 18. 总结

Go 入门阶段最重要的不是把所有语法背下来，而是形成这几个习惯：

- 写小函数
- 显式处理错误
- 用日志记录关键过程
